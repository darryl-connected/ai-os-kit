# Optional profile template

Stable profile facts belong in `context/about-me.md`, not in global harness instructions. Onboarding saves only new confirmed facts; you do not need to fill this in separately. If you prefer manual setup and have no profile yet, use this shape in your profile:

```markdown
# Profile

- Role:
- Team:
- Project:
- Optional working or writing preferences:
```

Keep project status in project notes. Keep connector scope in `connections.md`. Do not overwrite a profile that already works.
