# Meetings and tasks vault (Pi)

Read [operating rules](templates/OPERATIONS.md). Stable profile facts live in `context/about-me.md`, connection scope in [connections.md](connections.md), and current facts in each project's own notes. Read the relevant project's `README.md` when needed; ordinary project notes are not loaded for you.

Use `/skill:onboard` to start or resume with one task and `/skill:meeting-intake` to review and file a meeting. Consult before editing existing notes. Keep full originals separate and obtain separate explicit approval before shared-service writes.
